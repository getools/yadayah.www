AI Server

Limits the Puget AI server's internet traffic so it doesn't compete with a live show. Upload = data leaving the AI server (results sent back to the website, anything it sends out); Download = data arriving (audio sent in for transcription, model and image downloads). Local-network and SSH traffic is never limited. Changes save automatically and reach the AI server within about 15 seconds.
Limit During Shows
Apply the limits below automatically while a show is live (the red LIVE preview in the upper left of the site). Upcoming/scheduled streams don't count.
Manually Limit
Apply the limits below now, regardless of whether a show is running.
